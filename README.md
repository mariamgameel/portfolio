# Mariam Gameel Ibrahim — Software Engineer Portfolio

An executive, editorial Bento-grid personal portfolio website for **Mariam Gameel Ibrahim**, **Full-Stack Software Engineer**.

## 🎨 Aesthetic & Design Identity
- **Visual Style**: Luxury Editorial Bento Grid with Royal Burgundy accents and Antique Alabaster surfaces.
- **Palette**:
  - Sand / Taupe Canvas: `#AE9679`
  - Antique Alabaster Card Surface: `#F1DDC0`
  - Royal Burgundy: `#4D0A0D`
  - Warm Wine: `#5F2B24`
  - Deep Espresso Typography: `#1E0A05`
- **Typography**:
  - *Cormorant Garamond* (Editorial Serif Headlines)
  - *Plus Jakarta Sans* (Clean UI & Body)
  - *JetBrains Mono* (Terminal & Code Blocks)

## 🚀 Key Features
- **Sticky Burgundy Navigation Pill**: Quick navigation, live availability badge, social links, and one-click CV download.
- **Interactive Monospace Terminal**: Clickable commands (`stack`, `projects`, `contact`, `clear`) simulating an active shell session.
- **Human-Centered Psychology Advantage**: Showcasing how Mariam's B.Ed. in Psychology enhances software engineering, user experience, and API ergonomics.
- **Production Systems Showcase**:
  - **HRMS**: AI-Powered Enterprise Human Resources platform (Laravel 12, React, MySQL, Ollama Local LLMs, Sanctum RBAC).
  - **Pediatric Handover Clinical System**: Healthcare coordination platform (React, Node.js, Express, MongoDB, OWASP defenses).
- **Interactive Architecture Modals**: Click "Inspect Architecture" on any project to view technical accomplishments and system specs.
- **Category Filter**: Filter projects by All, Full-Stack, AI & Local LLM, and Healthcare.
- **One-Click Actions**: Direct PDF CV download, email copy with toast alert, and direct links to GitHub and LinkedIn.

## 💻 Local Preview
Run any local static server:
```bash
python -m http.server 5500
# Open http://localhost:5500 in your browser
```

## 📦 Instant Deployment Options
- **GitHub Pages**: Push this repository to GitHub and enable Pages in repository settings.
- **Vercel**: Import repository on Vercel or run `npx vercel`.
- **Netlify**: Drag and drop the folder onto Netlify or deploy via git.
